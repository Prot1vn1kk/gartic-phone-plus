# Gartic Phone Plus

Userscript для [Gartic Phone](https://garticphone.com): расширенное рисование, поиск референсов, плеер процесса рисования и настройки. Один файл, без подгрузки внешнего кода и без аналитики.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Яндекс Браузер, Opera).
2. В Chrome/Edge откройте страницу расширения Tampermonkey → «Сведения» и включите **«Разрешить пользовательские скрипты»** (без этого userscript-ы в новых версиях Chrome не запускаются).
3. Откройте ссылку **[установить gartic-phone-plus.user.js](https://raw.githubusercontent.com/Prot1vn1kk/gartic-phone-plus/main/dist/gartic-phone-plus.user.js)** и нажмите «Установить» в окне Tampermonkey.
4. Откройте garticphone.com. В правом нижнем углу появится кнопка **GP+**.

Обновления Tampermonkey подтягивает сам из этого репозитория.

## Что умеет

### Рисование (во время своего хода)
Скрипт кладёт поверх холста свой слой и сам отправляет штрихи на сервер в формате игры. Другие игроки без скрипта видят рисунок как обычно.

| Функция | Как вызвать |
|---|---|
| Инструменты: кисть, ластик, линия, прямоугольник, эллипс (контур и залитые), заливка | кнопки игры, панель «Студия», клавиши B, E, L, U, Shift+U, O, Shift+O, K |
| Ластик, пока зажата клавиша | C |
| Ровные фигуры: квадрат, круг, линия с шагом 15° | зажать Q |
| Фигура от центра | зажать R |
| Пипетка (ПКМ — в дополнительный цвет) | зажать Alt и кликнуть |
| Толщина / насыщенность / яркость цвета мышью | зажать Ctrl / Shift / V и тянуть |
| Быстрая толщина 4, 12, 20, 28, 36; толщина до 400 px | 1–5, `[` `]`, ползунок |
| Насыщенность | `,` `.` |
| Основной и дополнительный цвет (ПКМ рисует дополнительным) | X — поменять местами |
| Палитра под курсором | Tab |
| Масштаб колесом, к курсору, сброс | колесо, `+` `−`, Z+тянуть, S, A |
| Перемещение и поворот холста | Пробел+тянуть, средняя кнопка мыши; Ctrl+Пробел+тянуть (Shift — шаг 15°) |
| Зеркальный вид по горизонтали и вертикали (только для вас) | M, Shift+M |
| Чёрно-белый просмотр, сетка | W, G |
| Симметрия: вертикальная, горизонтальная, 4 четверти, радиальная, мандала (2–24 лучей) | T, панель «Студия» |
| Отмена / повтор | Ctrl+Z, Ctrl+Y |
| Сохранить PNG | Ctrl+S или кнопка скачивания игры |
| Очистить холст (с подтверждением) | Shift+Delete |
| Сглаживание линий 0–8, допуск заливки | настройки |
| Подтверждение «Готово» | настройки |

Все клавиши переназначаются: меню **GP+ → Клавиши**.

### Панель «Студия» (клавиша H)
Выбор цвета (квадрат насыщенности/яркости и полоса оттенка), HEX, последние цвета, цветовой круг (комплементарные, триада, аналоговые, тетрада, оттенки), палитры (встроенные, «Мои цвета», импорт `.aco`, `.gpl`, `.txt`), кисть, симметрия, вид.

### Референсы (клавиша P)
- Поиск картинок прямо в игре через открытые API **Wikimedia Commons** и **Openverse**.
- Кнопки «Google ↗» и «Pinterest ↗» открывают поиск в новой вкладке. Картинку оттуда можно перетащить в окно, вставить Ctrl+V или добавить по ссылке.
- Каждая картинка открывается в плавающем окне: перемещение, изменение размера, колесо — масштаб, двойной клик — вписать, прозрачность, «булавка» (клики проходят сквозь окно, можно рисовать под ним). Окна с картинками по ссылке запоминаются.

### Таймлапс
В альбоме на каждом рисунке появляется кнопка ▶; также работает двойной клик или средняя кнопка мыши по рисунку. Плеер: пуск/пауза, перемотка, скорость ×0.25–×16, сохранение PNG, запись видео WebM. На ходе «опиши рисунок» так же открывается предыдущий рисунок.

### Общее
Экспорт и импорт всех настроек, клавиш и палитр в JSON; акцентный цвет и прозрачность панелей; сброс.

## Чего нет и почему
- **Аватары, глобальный банлист, подписка, вход через Twitch** — в оригинальном моде они работают через серверы автора мода. Без своего сервера их не повторить.
- **Поиск Google и Pinterest внутри окна** — оригинал парсит закрытые эндпоинты этих сайтов с подменой заголовков. Здесь вместо этого открытые API и открытие поиска во вкладке.

## Разработка

```sh
sh build.sh            # склеивает src/*.js в dist/gartic-phone-plus.user.js и проверяет синтаксис
node test/fill.test.js # проверка упаковки заливки
```

Протокол игры (socket.io): `42[2, событие, данные]`. Штрих — событие 7 `{t, d, v}`. Заливка — набор прямоугольников `[x, y, w, h, k]`, где `k = 5 × индекс соседнего родительского прямоугольника`; сервер отбрасывает заливки с неверными ссылками.
