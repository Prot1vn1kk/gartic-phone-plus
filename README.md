# Gartic Phone Plus

Userscript для [Gartic Phone](https://garticphone.com): расширенное рисование, поиск референсов, плеер процесса рисования и настройки. Один файл, без подгрузки внешнего кода и без аналитики.

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Яндекс Браузер, Opera).
2. В Chrome/Edge откройте страницу расширения Tampermonkey → «Сведения» и включите **«Разрешить пользовательские скрипты»** (без этого userscript-ы в новых версиях Chrome не запускаются).
3. Откройте ссылку **[установить gartic-phone-plus.user.js](https://raw.githubusercontent.com/Prot1vn1kk/gartic-phone-plus/main/dist/gartic-phone-plus.user.js)** и нажмите «Установить» в окне Tampermonkey.
4. Откройте garticphone.com. Кнопка **GP+** появится в шапке игры рядом с кнопкой звука (на главной — рядом с выбором языка).

Обновления Tampermonkey подтягивает сам из этого репозитория.

## Как это выглядит

Интерфейс встроен прямо в экраны Gartic Phone и масштабируется вместе с игрой:

- **Левая колонка** вместо родной палитры — «спектр» (оттенки × светлота, серые, тона кожи), квадрат насыщенности/яркости с полосой оттенка, большой образец основного и дополнительного цвета с HEX, ползунки толщины и насыщенности, последние цвета. Другие палитры: цвета самой игры, встроенные наборы, «Гармония» от текущего цвета, «Мои цвета», импорт `.aco`, `.gpl`, `.txt`.
- **Правая колонка** под инструментами игры — симметрия (вертикальная, горизонтальная, 4 четверти, радиальная, мандала, число лучей), зеркальный и чёрно-белый просмотр, сетка, сброс вида, очистка холста.
- **Шапка книги** — кнопки «Настройки» и «Референсы», индикаторы масштаба, поворота, симметрии и очереди отправки.
- **Боковая панель референсов** прилипает к игре слева, игра сдвигается и уменьшается под неё.
- **Настройки и поиск референсов** открываются окнами в стиле диалогов игры.
- **Таймлапс** играет прямо в карточке рисунка в альбоме.

Клавиша **H** прячет и возвращает панели GP+ (родная палитра игры при этом возвращается на место).

## Что умеет

### Рисование (во время своего хода)
Скрипт кладёт поверх холста свой слой и сам отправляет штрихи на сервер в формате игры. Другие игроки без скрипта видят рисунок как обычно.

| Функция | Как вызвать |
|---|---|
| Инструменты: кисть, ластик, линия, прямоугольник, эллипс (контур и залитые), заливка | кнопки игры, клавиши B, E, L, U, Shift+U, O, Shift+O, K |
| Ластик, пока зажата клавиша | C |
| Ровные фигуры: квадрат, круг, линия с шагом 15° | зажать Q |
| Фигура от центра | зажать R |
| Пипетка (ПКМ — в дополнительный цвет) | зажать Alt и кликнуть |
| Толщина / насыщенность / яркость цвета мышью | зажать Ctrl / Shift / V и тянуть |
| Быстрая толщина 4, 12, 20, 28, 36; толщина до 400 px | 1–5, `[` `]`, ползунок в левой колонке |
| Насыщенность | `,` `.`, ползунок игры |
| Основной и дополнительный цвет (ПКМ рисует дополнительным) | X — поменять местами |
| Палитра под курсором | Tab |
| Масштаб колесом, к курсору, сброс | колесо, `+` `−`, Z+тянуть, S, A |
| Перемещение и поворот холста | Пробел+тянуть, средняя кнопка мыши; Ctrl+Пробел+тянуть (Shift — шаг 15°) |
| Зеркальный вид по горизонтали и вертикали (только для вас) | M, Shift+M, правая колонка |
| Чёрно-белый просмотр, сетка | W, G, правая колонка |
| Симметрия: вертикальная, горизонтальная, 4 четверти, радиальная, мандала (2–24 лучей) | T, правая колонка (число лучей — колесом по кнопке) |
| Отмена / повтор | Ctrl+Z, Ctrl+Y, кнопки игры |
| Сохранить PNG | Ctrl+S или кнопка скачивания игры |
| Очистить холст (с подтверждением) | Shift+Delete, правая колонка |
| Сглаживание линий 0–8, допуск заливки | настройки |
| Подтверждение «Готово» | настройки |

Все клавиши переназначаются: **GP+ → Клавиши**. Там же кнопка **«Как в gpmod»**: зеркало — CapsLock, Ч/Б — B, очистка — F.

**GP+ → Общее → Фиксированный размер**: игра не меняет размер вместе с окном браузера (удобно рисовать с референса на одном мониторе).

### Референсы (клавиша P или кнопка с картинкой в шапке)
- Панель слева от игры, ширина меняется перетаскиванием правой границы (двойной клик по границе — минимум/максимум).
- Поиск прямо в игре через открытые API **Wikimedia Commons** и **Openverse**; в строку поиска можно вставить ссылку на картинку. История открытых картинок.
- Кнопки «G» и «P» открывают поиск Google и Pinterest в новой вкладке: картинку оттуда можно перетащить в панель или вставить Ctrl+V. Файлы с компьютера — перетаскиванием или кнопкой «+».
- Просмотр: колесо — масштаб к курсору, ЛКМ — двигать, двойной клик или средняя кнопка — вписать, **ПКМ — назад к результатам**, Ctrl+клик — сохранить. Кнопки: масштаб, вписать, отразить, Ч/Б, сохранить.
- Кнопка-булавка открепляет картинку в плавающее окно поверх игры: прозрачность, отражение, Ч/Б, закрепление (клики проходят сквозь картинку — можно рисовать под ней).

### Таймлапс
В альбоме на каждом рисунке есть кнопка «Таймлапс»; также работает двойной клик или средняя кнопка мыши по рисунку. Плеер открывается прямо на месте рисунка:
- пуск/пауза (клик по рисунку, пробел), к первому/последнему штриху, медленнее/быстрее, перемотка, стрелки — по штриху;
- скорость x1…x800 (зажать индикатор «x10» и вести вбок или крутить колесо): до x100 штрихи рисуются плавно, выше — мгновенно;
- счётчик «текущий штрих / всего»;
- **график над перемоткой — сколько штрихов в какой период**, цвет столбика — основной цвет штрихов. Для своих рисунков — по реальному времени (скрипт записывает время каждого штриха), для чужих — по ходу рисования: игра время штрихов не передаёт;
- статистика: штрихи по инструментам, время рисования, штрихов в минуту, самый активный отрезок, использованные цвета;
- средняя кнопка — развернуть на весь интерфейс игры, двойной клик или F — **полный экран без рамок**;
- ПКМ — меню: сохранить процесс (.json), рисунок (PNG), видео (WebM). Сохранённый процесс открывается в **GP+ → Таймлапс → Открыть процесс**.

### Общее
Экспорт и импорт всех настроек, клавиш и палитр в JSON; акцентный цвет и прозрачность панелей; сброс.

## Чего нет и почему
- **Аватары, глобальный банлист, подписка, вход через Twitch** — в оригинальном моде они работают через серверы автора мода. Без своего сервера их не повторить.
- **Поиск Google и Pinterest внутри окна** — оригинал парсит закрытые эндпоинты этих сайтов с подменой заголовков. Здесь вместо этого открытые API и открытие поиска во вкладке.

## Разработка

```sh
sh build.sh            # склеивает src/*.js в dist/gartic-phone-plus.user.js и проверяет синтаксис
node test/fill.test.js # проверка упаковки заливки
```

Протокол игры (socket.io): `42[2, событие, данные]`. Штрих — событие 7 `{t, d, v}`. Заливка — набор прямоугольников `[x, y, w, h, k]`, где `k = 5 × индекс соседнего родительского прямоугольника`; сервер отбрасывает заливки с неверными ссылками.
